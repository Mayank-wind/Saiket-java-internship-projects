This repository contains six Java console applications completed during my Saiket Systems Java Development Internship.

## Projects

| # | Project | Description | Main Concepts |
|---|---|---|---|
| 1 | Calculator Application | Performs addition, subtraction, multiplication, and division. | Methods, conditionals, exceptions |
| 2 | Temperature Converter | Converts Celsius and Fahrenheit values. | Methods, formulas, input handling |
| 3 | To-Do List Application | Adds, displays, and completes tasks. | Records, lists, loops, OOP |
| 4 | Number Guessing Game | Generates a random number and tracks attempts. | Random numbers, loops, conditionals |
| 5 | Text File Analyzer | Counts lines, words, characters, and word matches. | File I/O, strings, streams |
| 6 | Basic Banking System | Handles deposits, withdrawals, balances, and transaction history. | Classes, inheritance, BigDecimal |

## Running a Project

Open any task folder in IntelliJ IDEA and run the Java class containing the `main` method.

### Calculator Application

```bash
cd "Task-1 Calculator"
javac -d out src/CalculatorApplication.java
java -cp out CalculatorApplication
```

### Temperature Converter

```bash
cd "Task-2 TemperatureConverter"
javac -d out src/TemperatureConverterApplication.java
java -cp out TemperatureConverterApplication
```

### To-Do List Application
